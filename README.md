# Flutter Party Organizer + Chatbot

Mobile app to organize parties. Users can select venue, food, decorations, and interact with a small chatbot. Built using Flutter and Bloc for smooth state management with backend.

## Features
- Plan all party elements (venue, food, decorations)
- Interactive chatbot for user guidance
- State management using Bloc
- Attractive and responsive UI

## Technologies
- Flutter (Dart)
- Bloc architecture for state management
- Backend API integration
- UI/UX Design
